## 🎯 AZ-900: Microsoft Azure Fundamentals

The AZ-900 learning path introduces the fundamental concepts of cloud computing and Microsoft Azure.

### Topics Covered

**1. Cloud Concepts**
- Cloud computing and deployment models
- IaaS, PaaS, and SaaS
- Shared responsibility model
- High availability, scalability, and elasticity
- Cloud pricing and consumption models

**2. Azure Architecture and Services**
- Azure regions, availability zones, and resource hierarchy
- Compute and networking services
- Azure Storage and redundancy
- Identity, access management, and security
- Azure management and deployment tools

**3. Azure Management and Governance**
- Cost management and pricing
- Azure Policy, resource locks, and tags
- Azure Monitor and Azure Advisor
- Service Health and governance tools
- Compliance and data protection
