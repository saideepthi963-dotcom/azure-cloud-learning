# Azure Privacy and Compliance

## What Is Compliance?

**Compliance** means following laws, regulations, and security standards to protect sensitive information.

For example, a hospital storing patient information in Azure must follow healthcare privacy regulations.

### Important Compliance Standards

| Standard | Purpose |
|---|---|
| **GDPR** | Protects personal data of individuals in the EU |
| **HIPAA** | Protects patient health information in the US |
| **NIST** | Provides cybersecurity guidelines and best practices |
| **CJIS** | Security requirements for US criminal justice information |
| **CSA STAR** | Cloud security assurance and assessment program |

## Microsoft Privacy and Compliance Tools

### 1. Microsoft Privacy Statement

Explains **what personal data Microsoft collects, how it uses it, and why**.

### 2. Microsoft Trust Center

Provides information about Microsoft's **security, privacy, compliance, and transparency practices**.

**Remember: Trust Center → Learn how Microsoft protects data.**

### 3. Service Trust Portal

Provides access to **Microsoft audit reports, compliance certifications, and trust documents**.

**Remember: Service Trust Portal → Find compliance and audit reports.**

### 4. Microsoft Purview Compliance Manager

Helps organizations **assess, track, and improve regulatory compliance**.

It provides:
- Compliance scores
- Recommended improvement actions
- Compliance assessments and evidence tracking

**Remember: Compliance Manager → Track compliance progress.**

## Special Azure Environments

### Azure Government

A separate Azure cloud environment designed for eligible **US government organizations and their partners**.

It supports government security and compliance requirements and is operated by screened US personnel.

### Azure China (21Vianet)

A separate Azure environment located in **China**, operated by **21Vianet**, rather than directly by Microsoft.

It supports organizations that need cloud services within China.
