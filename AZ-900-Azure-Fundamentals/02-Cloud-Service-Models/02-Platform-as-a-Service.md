# Platform as a Service (PaaS)

## 1. What Is PaaS?

**Platform as a Service (PaaS)** provides a complete development and deployment environment in the cloud.

It allows developers to **build, test, deploy, manage, and update applications without managing the underlying infrastructure**.

- Resources are accessed over a secure internet connection.
- Typically follows a pay-as-you-go pricing model.
- Supports simple applications and complex business applications.

**Example:** Azure App Service.

## 2. What Does PaaS Include?

PaaS includes everything provided by IaaS, along with additional development and platform services.

| IaaS Components | Additional PaaS Components |
|---|---|
| Servers | Middleware |
| Storage | Development tools |
| Networking | Database management systems |
| Compute resources | Business Intelligence (BI) services |

**Middleware:** Software that helps applications communicate and work together.

**BI (Business Intelligence):** Tools used to analyze business data and support decisions.

**Remember:** PaaS = Infrastructure + Development Platform.

## 3. Who Manages What in PaaS?

| Microsoft Azure Manages | Customer Manages |
|---|---|
| Physical infrastructure | Application code |
| Servers and networking | Applications developed |
| Operating systems | Application data |
| Middleware and runtime | Application configurations |
| Platform maintenance | User access and permissions |

**Key Point:** Developers focus on building applications while Microsoft manages the underlying platform.

## 4. Benefits of PaaS

- **Reduced Costs:** No need to purchase or maintain physical servers and much of the platform software.
- **Faster Development:** Built-in development tools simplify application creation.
- **Scalability:** Applications can increase or decrease capacity as needed.
- **High Availability:** Managed platform capabilities help improve application availability.
- **Less Maintenance:** Microsoft manages operating systems, middleware, and platform updates.
- **Simplified Development:** Built-in services reduce the amount of infrastructure-related code and setup required.

## 5. Common Use Cases

### 1. Application Development

PaaS provides tools and frameworks for developing and customizing cloud applications.

It supports the complete application lifecycle:

**Build → Test → Deploy → Manage → Update**

Developers can focus on application features instead of managing servers.

### 2. Analytics and Business Intelligence

PaaS can provide tools that help organizations:

- Analyze large amounts of data.
- Identify patterns and trends.
- Predict future outcomes.
- Improve business forecasting.
- Support product design and investment decisions.

## 6. IaaS vs. PaaS

| IaaS | PaaS |
|---|---|
| Provides computing infrastructure | Provides infrastructure and a development platform |
| Customer manages the operating system | Microsoft manages the operating system |
| Customer manages middleware | Microsoft manages the managed platform's middleware |
| More infrastructure management | Less infrastructure management |
| Suitable for lift-and-shift migrations | Suitable for application development |

## ⭐ Important AZ-900 Exam Points

- **PaaS = Platform as a Service.**
- Provides a cloud-based development and deployment environment.
- Includes servers, storage, networking, middleware, and development tools.
- Supports the complete application lifecycle.
- Microsoft manages the underlying infrastructure, operating systems, and platform components.
- Customers manage their applications, data, and applicable security settings.
- Supports scalability and high availability.
- Common uses include application development, analytics, and business intelligence.

**Easy Way to Remember:**

**IaaS → You manage the OS and applications.**

**PaaS → You manage your applications; Microsoft manages the underlying platform.**
