# Introduction to Cloud Computing

## What is Cloud Computing?

Cloud computing is the delivery of computing services
over the internet instead of relying on physical
infrastructure owned and maintained by an organization.

Microsoft Azure is Microsoft's cloud computing platform.

## Common Cloud Services

- Compute
- Storage
- Networking
- Databases
- Analytics
- Artificial Intelligence (AI)

## Key Characteristics

### 1. On-Demand Availability
Cloud resources can be provisioned whenever needed.

### 2. Scalability
Resources can be increased or decreased based on demand.

### 3. Pay-As-You-Go
Organizations pay based on their resource consumption.

## Benefits of Cloud Computing

- Reduced upfront hardware investment
- Faster resource deployment
- Flexible resource allocation
- Global availability
- Reduced physical infrastructure management
- Economies of scale

## Azure Cloud Services

- Azure Virtual Machines — Run virtual servers.
- Azure Storage — Store files and data.
- Azure App Service — Host applications without managing servers.

## AZ-900 Exam Points

- Cloud computing delivers services over the internet.
- Azure is Microsoft's cloud computing platform.
- Scalability allows resources to adjust to demand.
- Consumption-based pricing charges based on usage.
- Microsoft manages the underlying physical infrastructure.
