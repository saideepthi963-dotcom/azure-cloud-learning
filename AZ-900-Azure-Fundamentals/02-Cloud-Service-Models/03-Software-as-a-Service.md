# Software as a Service (SaaS)

## 1. What Is SaaS?

**Software as a Service (SaaS)** provides complete, ready-to-use applications over the internet.

Instead of installing and managing software on your own servers, you use applications provided and managed by a cloud service provider.

- Applications are commonly accessed through a web browser.
- Usually paid for through subscriptions or usage-based pricing.
- No need to purchase and maintain application servers.
- Users can access applications from different devices with an internet connection.

**Examples:** Microsoft 365, Outlook, Gmail.

**Remember:** SaaS = Use ready-made software over the internet.

## 2. How Does SaaS Work?

The cloud service provider hosts the application and its underlying infrastructure in its datacenters.

The provider manages:
- Physical servers and networking
- Operating systems
- Middleware
- Application software
- Software updates and maintenance
- Infrastructure and platform security

The customer manages:
- User accounts and permissions
- Their organization's data
- Applicable security settings
- How employees use the application

**Key Point:** The provider manages the software, while customers remain responsible for their users, data, and access settings.

## 3. Benefits of SaaS

- **Quick Setup:** Start using applications without installing complex infrastructure.
- **Lower Upfront Costs:** No need to purchase application servers.
- **Less Maintenance:** The provider manages software updates and infrastructure.
- **Easy Access:** Use applications through the internet.
- **Flexible Pricing:** Pay through subscriptions or usage-based plans.
- **Managed Availability:** Providers deliver availability and security commitments through applicable service agreements.

## 4. Common SaaS Use Cases

| Use Case | Examples |
|---|---|
| Email | Outlook, Gmail |
| Calendaring | Online calendar applications |
| Productivity | Microsoft 365 |
| Collaboration | Microsoft Teams |
| Customer Relationship Management (CRM) | Applications used to manage customer relationships |
| Enterprise Resource Planning (ERP) | Applications used to manage business operations |
| Document Management | Applications used to store and manage documents |

### Example: Web-Based Email

When using Outlook on the web:

1. You open your browser and sign in.
2. The email application runs on the provider's infrastructure.
3. Your emails are stored on the provider's systems.
4. You access your mailbox over the internet.

You don't need to install or maintain an email server.

## 5. IaaS vs. PaaS vs. SaaS

| IaaS | PaaS | SaaS |
|---|---|---|
| Provides infrastructure | Provides a development platform | Provides ready-to-use software |
| Customer manages the OS and applications | Customer manages applications and data | Customer manages data, users, and access |
| Example: Azure VM | Example: Azure App Service | Example: Microsoft 365 |
| Most infrastructure management | Less infrastructure management | Least infrastructure management |

## ⭐ Important AZ-900 Exam Points

- **SaaS = Software as a Service.**
- Provides complete applications over the internet.
- Usually follows subscription-based or usage-based pricing.
- The provider manages infrastructure, operating systems, middleware, and application software.
- Customers remain responsible for their data, identities, permissions, and applicable security configurations.
- Common SaaS examples include email, calendaring, Microsoft 365, and business applications.
- SaaS allows organizations to use software quickly without building or maintaining the underlying infrastructure.

**Easy Way to Remember:**

**IaaS → Manage your servers and software.**

**PaaS → Build your applications without managing servers.**

**SaaS → Use ready-made applications without managing the underlying platform.**
